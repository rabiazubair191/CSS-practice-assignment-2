# ⌨️ Interactive CSS Keyboard Design

A modern, skeuomorphic keyboard interface built using pure **HTML5** and **CSS3**. This project focuses on advanced layout structuring, box-shadow depth styling, and custom glowing accent states.

## ✨ Key Features
* **Skeuomorphic Design:** Utilizes multi-layered CSS box shadows and gradients to give physical keys a realistic, tactile elevation.
* **Custom States:** Features distinctive styling and neon accent glows for specialized keys like *Caps Lock*, *Backspace*, *Space*, and targeted highlights.
* **Responsive Layout Architecture:** Built with meticulous alignment to mirror standard QWERTY keyboard proportions across varying widths (Tab, Shift, Spacebar).

## 🛠️ Built With
* **HTML5** (Semantic markup & container structure)
* **CSS3** (Flexbox/Grid alignments, box-shadows, pseudo-classes, and custom styling)
* **Git & GitHub** (Version control and deployment)

## 💡 What I Learned
Through this project, I strengthened my understanding of CSS positioning, fine-tuning complex shadow properties to achieve realistic depth, and managing precise spacing for multi-row UI components without relying on external UI libraries.
